# **🔵 1\. GOOGLE SETUP (NON-NEGOTIABLE)**

### **Google Business Profile**

* Business name correct (no keywords)

* Correct categories

* Suburb service areas

* 20+ photos uploaded

* Logo uploaded

* SMS or postcard verified

* Messaging turned on

* Services added (with keywords)

* Completed description

* Weekly posts scheduled

* Review link copied

* Questions & Answers added (FAQ)

### 

### **Google Analytics (GA4)**

You need this for tracking:

* site visits

* suburb traffic

* conversions

* call clicks

* WhatsApp clicks

SETUP:

* Create GA4

* Create Data Stream

* Add GA4 tag to WordPress (Hostinger → plugin or Tag Manager)

* Test real-time traffic

### **Google Search Console**

This is essential for ranking.  
 It tells you:

* What do you rank for

* What people search

* site errors

* indexing issues

SETUP:

* Add property

* Verify via DNS or file

* Submit sitemap

### **Google Tag Manager**

Optional but smart for your business.

Use it for:

* call tracking

* WhatsApp tracking

* form submissions

* button clicks

### **Google Maps Embeds**

Add a map embed to your contact page.  
This boosts local trust.

# **🟣 3\. TECHNICAL SEO (BACK-END SETTINGS)**

### **Yoast or RankMath installed**

Use one. Not both.

### **Titles \+ Meta Descriptions**

Every service page needs:

* strong keyword

* location

* short CTA

Example:  
 "Pool Replastering Cape Town | Clean Finishes & Fast Quotes"

### **Sitemap Enabled**

Make sure your sitemap.xml is visible.  
 Add to Search Console.

### **Robots.txt**

Ensure it is not blocking your site.

### **Mobile Optimization**

Google ranks mobile first.  
 Your site must be:

* fast

* responsive

* easy to tap buttons

### **Site Speed (important)**

Check with PageSpeed Insights.  
 Fix:

* images too heavy

* unused plugins

* slow themes

* no caching

### **SSL Certificate**

Must be active.  
 No http. Always https.
