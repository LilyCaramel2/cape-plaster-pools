# Docs

This folder contains all authoritative reference PDFs for
Cape Plaster & Pools.

Rules:
- PDFs live ONLY in /docs
- No PDFs in /assets
- No PDFs embedded or inlined in HTML
- PDFs are read-only reference material

Usage:
- /policy defines architectural and layout law
- /docs defines brand, SEO, content, and operational truth
- Website code must not contradict either

If a change conflicts with a PDF in /docs, the change is invalid.
